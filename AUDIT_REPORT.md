Дата: 26.10.2026 · Ветка: `arena/0953ae96-ai-call-center`
Методология: всё проверялось в headless-окружении без аудиооборудования,
сети и LLM-ключей (офлайн-мозг, mock STT/TTS, offscreen Qt).

## 2. Найденные и устранённые дефекты

### Диалоговый движок
1. **Зависание на смене мнения.** Слоты перезаписывались, но подобранный
   товар и черновик заказа оставались от старых параметров — клиент
   «пересчитал на 12В», а в ответе фигурировал 24В. Теперь смена
   инженерных слотов инвалидирует `last_product`/`order_result` в
   `ToolExecutor`, заказ пересчитывается в том же ходе.
2. **Тупик `ORDER_CREATED`.** Из состояния не было выхода, кроме закрытия;
   добавлены переходы обратно в COLLECTING/QUOTING при изменении параметров.
3. **Дубль заказа.** Повторное «да, оформляем» запускало `create_order`
   ещё раз — теперь заказ фиксируется однократно, ответ «уже зафиксирован».
4. **Попугай на возражениях.** Повторное «дорого/скидку» возвращало ту же
   фразу; добавлены вторые линии ответов (`_OBJECTION_FOLLOWUPS`),
   новые триггеры «робот» и «соедините с человеком».
5. **Не было обработки тишины.** Введён `handle_silence()`: два переспроса,
   на третьем — автозавершение; реальная фраза сбрасывает счётчик.
6. **Парсер речи не понимал устные числа.** «двадцать четыре вольта»
   превращалось в 20 и 4 (бралось первое число); добавлен сборщик
   русских числительных (единицы/десятки/сотни/тысячи), жаргон
   («двадцатьчетверка», «шток тридцатка»), метры→мм, «полтора».
7. **Деньги засоряли инженерные слоты.** «скиньте пятьсот рублей» больше
   не создаёт `force_n=500` — регексы требуют единицы измерения.

### Импорт прайс-листов
8. **NBSP ломал числа.** `7 500` с неразрывным пробелом давал 0
   (сырая строка в регексе не матчила `\u00a0`); санитайзер теперь
   нормализует все Unicode-пробелы и валютные токены (`₽, руб., $, НДС`).
9. **Объединённые ячейки терялись.** В read-only режиме openpyxl не
   отдаёт merged-диапазоны; они читаются напрямую из XML листа xlsx,
   значение якоря распространяется на покрытые ячейки (только на них —
   пустые цены соседей не наследуются).
10. **Дубли артикулов.** Файл с повторным SKU создавал две строки и
    конфликт в SQLite; дедуп на парсинге (побеждает последняя строка) +
    `ON CONFLICT DO UPDATE` в пакетной вставке.
11. **Пустые строки-шапки** в начале файла сбивали определение заголовков —
    добавлен пропуск ведущих пустых строк для xlsx/xls/csv.
12. **Автоопределение разделителя** ошибалось на узких CSV — теперь
    доминанта по первой строке (`;`, tab, `|`, `,`).

### PDF и хранилище
13. **Кириллица в Helvetica.** Стандартные шрифты reportlab не содержат
    кириллицы; встроены DejaVu Sans/Bold (free license, шрифты в репозитории
    вместе с лицензией), шрифт подключается через PyInstaller-совместимый
    резолвер `app/paths.py`.
14. **Не было суммы прописью** — реализован полный русский числительный
    (рубли/копейки, род, плюрализация, миллионы).
15. **WAL рос неограниченно** (4 МБ после 50 звонков) — добавлен
    `PRAGMA synchronous=NORMAL` и пассивный checkpoint после каждого
    звонка; WAL держится ~230 КБ.
16. **Кажущаяся утечка RSS +33 МБ.** Расследование показало: арены glibc
    не возвращают ОС (после `malloc_trim` прирост 0,0 МБ на 200 звонках),
    Python-объекты не текут (~50 КБ tracemalloc). Методика бенчмарка
    разделяет прогрев кэшей и измеряемое окно.

## 4. Демонстрация клиенту за 60 секунд

1. **0:00** — Запустить `VoiceSalesAgent.exe` (или `python run.py`).
   Вкладка «Реестр звонков», внизу слева статус SIP — не требуется.
2. **0:08** — Вкладка «Источник данных» → чип **«Актуаторы»** в блоке
   «Демо-каталог в один клик» → 50 позиций загружены, проверка поиска
   в строке «актуатор 24В 300мм» показывает подбор мгновенно.
3. **0:20** — Верхняя панель → кнопка **«Текстовый тест»** →
   окно симулятора, AI уже поздоровался.
4. **0:25** — Вставить по очереди (есть чипы быстрых фраз):
   - «Нужен актуатор на 24 вольта, ход 300 мм, одна штука» →
     подбор, цена, бейдж вызова инструмента, RTT ~1 мс;
   - «Это дорого, а скидку дадите?» → обработка возражения;
   - «Да, оформляем заказ» → номер `ЛОКАЛ-…`, состояние DONE.
5. **0:45** — «Положить трубку» → статус «ЗАВЕРШЁН», окно остаётся
   открытым с полным транскриптом.
6. **0:50** — В реестре новая строка `+7 (999) 000-TEST` с бейджем
   «Текстовый тест»; в инспекторе — диалог, заказ и активная кнопка
   **«Открыть КП»**: PDF с реквизитами, НДС и суммой прописью.

Микрофон, интернет и LLM-ключи для демо не нужны.

## 6. Известные ограничения

- Silero VAD, faster-whisper и F5-TTS не бандлятся в exe (сотни МБ):
  ставятся как документированные дополнения, энергетический VAD и mock
  работают из коробки.
- В песочнице нет PortAudio: TTS-озвучка симулятора проверена кодом
  воспроизведения с mute-fallback, аппаратный прогон требует Windows/audio.
- pymupdf используется только для рендера PDF-скриншотов и исключён из
  рантайм-зависимостей и из PyInstaller-сборки.
