# Контракт HTTP-сервиса 1С для AI-продавца

Агент обращается к опубликованной базе 1С (УТ, ERP, КА, УНФ) по Basic Auth
технического пользователя. Базовый URL задаётся во вкладке «Подключение к 1С»,
например `http://192.168.1.100/trade_base/hs/ai_sales/`.

## 1. `GET ping` — проверка связи

Ответ:

```json
{ "ok": true, "warehouses": ["Основной склад", "Склад №2"] }
```

## 2. `POST catalog/lookup` — цена и наличие

Запрос:

```json
{
  "query": "актуатор",
  "params": { "category": "актуатор", "voltage": 24, "stroke_mm": 300 }
}
```

Ответ (отсутствие номенклатуры — `found: false`, не ошибка HTTP):

```json
{
  "found": true,
  "article": "ACT-24-300",
  "name": "Актуатор линейный 24В, ход 300мм",
  "price": 11500,
  "stock": 14,
  "warehouse": "Основной склад"
}
```

## 3. `POST orders/create` — заказ покупателя

Запрос:

```json
{
  "phone": "+79182041122",
  "comment": "Доставка в Краснодар",
  "delivery_address": "г. Краснодар, ул. ...",
  "items": [
    { "article": "ACT-24-300", "name": "Актуатор 24В 300мм",
      "quantity": 1, "price": 11500, "unit": "шт", "sum": 11500 }
  ]
}
```

Ответ:

```json
{ "ok": true, "number": "Заказ 8412", "number_1c": "Заказ 8412" }
```

## Пример модуля HTTP-сервиса (платформа 1С, язык BSL)

```bsl
Функция catalog_lookup_post(Запрос)

	ТелоЗапроса = ПрочитатьJSON(Запрос);
	Параметры = ТелоЗапроса.Параметры;

	Запрос1С = Новый Запрос;
	Запрос1С.Текст =
	"ВЫБРАТЬ ПЕРВЫЕ 1
	|	Номенклатура.Артикул КАК Артикул,
	|	Номенклатура.Наименование КАК Наименование,
	|	Номенклатура.Цена КАК Цена,
	|	Остатки.КоличествоОстаток КАК Остаток
	|ИЗ
	|	Справочник.Номенклатура КАК Номенклатура
	|		ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ОстаткиТоваров.Остатки() КАК Остатки
	|		ПО Остатки.Номенклатура = Номенклатура.Ссылка
	|ГДЕ
	|	Номенклатура.НапряжениеВ = &Напряжение
	|	И Номенклатура.ХодШтокаМм = &Ход";
	Запрос1С.УстановитьПараметр("Напряжение", Параметры.voltage);
	Запрос1С.УстановитьПараметр("Ход", Параметры.stroke_mm);

	Выборка = Запрос1С.Выполнить().Выбрать();
	Если Не Выборка.Следующий() Тогда
		Возврат ОтветJSON(Новый Структура("found", Ложь));
	КонецЕсли;

	Возврат ОтветJSON(Новый Структура(
		"found, article, name, price, stock, warehouse",
		Истина, Выборка.Артикул, Выборка.Наименование,
		Выборка.Цена, Выборка.Остаток, "Основной склад"));

КонецФункции
```

Альтернативный режим без разработки на стороне 1С — стандартный OData
(`/odata/standard.odata/`), маппинг реквизитов настраивается в интерфейсе.
